# PaperLeaf Map-Reduce 跨论文 A/B draft 数据集

该目录用于比较现有单 Agent v1 与并行 Map-Reduce v2。当前版本包含 36 个
3～10 篇论文的复杂任务和 12 个对照，共 48 例。任务只引用
`paperleaf-rag-v1` 中已经过页码锚点检查的源题，不重新分发 PDF。

## 当前状态

- `annotation_status=draft`；
- `frozen=false`；
- `quality_claims_allowed=false`。

组合问题、反证关系和预期冲突仍需人工逐条复核。完成复核、重新计算文件哈希并由维护者
签字前，本数据集只能验证 Schema、协议、故障降级和评测代码，不能证明 v2 优于 v1，
也不能用于简历中的准确率或质量提升表述。

## 组成

| 类别 | 数量 | 目的 |
|---|---:|---|
| 系统比较 | 16 | 比较方法、数据、限制和实验设计 |
| 复合主张核验 | 12 | 覆盖支持、反证和证据空白流程 |
| 研究脉络 | 8 | 构建有来源的研究演进图 |
| 单篇对照 | 4 | 确认简单任务继续使用 v1 |
| 不可回答对照 | 3 | 测量错误作答 |
| Prompt Injection 对照 | 3 | 验证不可信指令不能越权 |
| Scope 越权对照 | 2 | 验证进入图前拒绝 |

`dev` 仅用于调试评测器；Go/No-Go 只读取 `test`。真实 A/B 必须保证每对 Run 的
问题、冻结论文范围、集合快照和模型配置哈希一致，并交替使用 AB/BA 顺序。

Token 暂以现有 Context 预算器估算，报告字段必须写作 `estimated`；在 Provider
真实 usage 尚未持久化前，不得称为实际计费 Token。
