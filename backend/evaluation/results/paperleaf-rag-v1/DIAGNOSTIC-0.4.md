# PaperLeaf 0.4 检索与证据门禁诊断

本报告使用 `paperleaf-rag-v1` 的既有 test 集。该集合已经在 0.3 阶段被查看和用于诊断，
所以以下结果不是盲测 holdout，也不能用于声称泛化性能已经达标。所有结果都使用同一批
20 篇固定 PDF、同一页级标注与 Recall@5 分母（90 个期望证据组）。

| 方案 | Recall@5 | MRR@5 | test 本机 p95 | 决定 |
|---|---:|---:|---:|---|
| 页级 RRF | 68/90（75.6%） | 58.9% | 51 ms | 保留并接入生产页去重 |
| BGE-small dense | 49/90（54.4%） | 31.9% | 76 ms | 不采用 |
| BGE-small + BM25/RRF | 59/90（65.6%） | 44.0% | 123 ms | 不采用 |
| 页级 RRF + Cross-Encoder | 65/90（72.2%） | 52.8% | 5,128 ms | 不采用 |
| 页级 RRF + 句窗 Cross-Encoder | 63/90（70.0%） | 49.5% | 4,996 ms | 不采用 |
| 细粒度窗口 BM25 | 63/90（70.0%） | 57.0% | 17 ms | 不采用 |
| RRF + 窗口通道 | 66/90（73.3%） | 59.0% | 68 ms | 不采用 |

页级 RRF 的 Recall@40 为 90/90（100%），说明正确页都进入了较深候选池；当前小型
Cross-Encoder 没有把它们稳定推回 Top-5，且引入约 5 秒 p95，因此不能仅凭“增加了重排器”
就视为改进。BGE-small 与 Cross-Encoder 的输入窗口也小于当前约 700-token Chunk，长证据的
截断是后续多向量/分层检索需要单独验证的问题。

确定性线上同源门禁在同一诊断集上把不可回答错误作答从 10/10 降到 1/10；代价是有依据
问题的引用覆盖率只有 22/80（27.5%）。它比“列表非空即回答”安全，但仍未达到错误作答率
≤5% 和引用覆盖率 ≥90% 的联合目标。配置模型后新增的答案支持检查尚未在冻结 holdout 上
量化，因此不发布模型检查准确率。

0.4 的采用项只有：扩大混合候选池、页级去重与通道合并、确定性检索质量门禁、可选答案
支持检查，以及前端可公开质量摘要。下一轮在不查看结果的留出集上验证前，不修改本报告的
诊断口径。
