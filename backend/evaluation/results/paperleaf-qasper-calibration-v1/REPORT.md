## 阶段结论

- BM25 → RRF：Recall@5 提升 `+4.9` 个百分点。
- RRF → 页去重：Recall@5 提升 `+6.6` 个百分点。
- 邻页加权：Recall@5 变化 `+1.6` 个百分点，因此不作为默认方案。
- 固定三倍向量权重把 Recall@5 提升 `+1.6`、MRR@5 提升 `+3.2` 个百分点，但在旧 v1 test 上分别从 `68/90` 退化到 `62/90`，因此淘汰。
- 自适应候选保持 Recall@5 为 `51/61`，把 MRR@5 从 `59.0%` 提到 `60.0%`，并通过旧 v1 回归门槛；但该差异随后没有在预注册 holdout 上复现，未进入生产默认链路。
- 严格拒答：dev 不可回答错误作答率为 `0.0%`，引用覆盖率为 `4.2%`；安全性提升伴随覆盖损失。
- 线上同源质量门禁：dev 不可回答错误作答率为 `33.3%`，引用覆盖率为 `10.4%`。

- 评测只比较检索、物理页引用和确定性拒答，不声称衡量生成模型的完整答案质量。
- PDF 原件不随仓库分发；清单固定官方下载地址、版本、SHA-256 与页数。
