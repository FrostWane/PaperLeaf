# PaperLeaf 正式评测报告（2026-08-14）

## 结论

本轮已经完成两套 RAG 检索评测、100 题真实端到端问答和 30 题/90 Run 的
v1/v2/v3 对照。自动证据链完整，人工盲评尚未填写，因此总状态为
`automatic_evidence_complete_human_review_pending`。

本轮没有得到“最终组合方案优于生产基线”或“多 Agent 提升回答质量”的证据。相反，
正式隐藏集显示最终组合方案的页级 micro Recall@5 从 64.2% 降至 61.6%，差异未达到
统计显著，MRR@5 显著下降；
v3 Specialist 的完成率和跨论文覆盖也低于 v1/v2。负结果全部保留。

## 1. 环境与协议

- 已揭盲诊断集：20 篇、90 问，`diagnostic_not_blind`；
- 首次隐藏集：70 篇、100 问，与四套既有开发/评测论文集合零重叠；
- 隐藏集配额：50 单篇、30 跨论文、10 多证据、10 不可回答；中文 50、英文 50；
- 切分：`structure_aware_v2`，严格不跨物理页；
- Embedding：Ollama `qwen3-embedding:0.6b`，1024 维，revision 2，
  `paper_context_v2`；
- 检索候选池 Top-40，最终 K=5；七个方案使用相同问题、论文范围与 Chunk 快照；
- 旧 MiniLM 句窗 Reranker 保持关闭；
- 配对 Bootstrap：10,000 次，固定种子 20260814；
- 隐藏集首次运行后公开冻结 oracle；此后该集合只能用于复核或已揭盲诊断。

### 分桶结果

生产基线的页级 micro Recall@5：单篇 46/50（92.0%）、跨论文 38/90（42.2%）、
多证据 18/19（94.7%）；中文问题 56/110（50.9%），英文问题 46/49（93.9%）。
英文桶包含全部 10 道不可回答题，中文桶包含全部 30 道跨论文题，因此语言与题型存在
混杂，不能把差异归因于语言本身。

最终组合的对应结果为：单篇 48/50（96.0%）、跨论文 32/90（35.6%）、多证据
18/19（94.7%）；中文 51/110（46.4%），英文 47/49（95.9%）。

### 配对结论

- 最终组合相对生产基线页级 micro Recall@5：102/159（64.2%）→98/159
  （61.6%），Δ -2.5 个百分点，按题配对重采样并在每次样本内汇总页级分子/分母得到的
  95% CI 为 `[-8.5, +3.9]`，没有稳定提升；
- 页级 macro Recall@5 是逐题命中比例的等权平均：Δ 0.0 个百分点，95% CI
  `[-4.4, +4.8]`。该区间不能再标作 micro Recall 区间；
- MRR@5：Δ -7.4 个百分点，95% CI `[-13.8, -1.1]`，显著下降；
- 完整证据组：Δ +1.0 个百分点，95% CI `[-3.0, +5.0]`；
- required-paper coverage：Δ 0.0，均为 100%；
- 不可回答错误取证率：生产基线与最终组合均为 10/10（100%）。

因此本轮不能将最终组合设为“质量更高”的新基线。生产基线仍是本轮正式隐藏集的主要
对照结果；多粒度重排的诊断集增益未在隐藏集复现。

## 6. Worker 强杀恢复

真实 v3 Run `5987dd89-cf15-4a43-8771-f9a77582f9a6` 启动三个 Specialist；s3、s1
完成而 s2 尚未完成时，唯一 Worker 被 `docker kill` 强制终止。没有手工修改数据库，
30 分钟租约自然过期后，新 Worker 将同一 Job 领取为第 2 次执行。持久事件证明：

- 第一次领取已完成 s1、s3；第二次领取没有再次启动或再次成功执行这两个分支；
- 第二次领取只启动未完成的 s2；s2 随后超时，系统基于 s1/s3 做 partial merge；
- 父 Run 最终 `completed`，总时长 227.1 秒；
- 使用旧 claim token 的迟到事件写入探针被拒绝，数据库没有产生探针事件；
- 两次领取的安全事件 epoch 不同，事件 sequence 连续且唯一。

该单次故障注入证明了这一崩溃点上的 Checkpoint 恢复、已完成分支不重复执行和
claim-token fencing；它不是所有故障位置的统计稳定性证明。

## 9. 不能写进简历的结论

- “最终组合方案把 Recall@5 从 64.2% 提升到更高值”；实际为 61.6%，且差异不显著；
- “多粒度 Reranker 在隐藏集稳定提升”；诊断集增益没有复现；
- “v3 多 Agent 提升回答质量或稳定性”；当前完成率和覆盖率更低，人工偏好为空；
- “回答准确率 95%”；95% 是模型辅助主张支持率，Gold 引用命中仅 26.2%；
- “不可回答题拒答可靠”；当前错误取证和端到端误答均为 10/10；
- “成本就是 $0.03～$0.06”；仅部分模型调用有 Token 遥测，且未区分缓存，不是总成本；
- “Worker 在任意崩溃点都能无损恢复”；本轮只验证了一个确定崩溃点，且未完成分支恢复
  后仍发生超时；
- 将 75.6%、85.4% 或 91.7% 改写成本轮同集提升；它们来自不同历史集合和口径。
