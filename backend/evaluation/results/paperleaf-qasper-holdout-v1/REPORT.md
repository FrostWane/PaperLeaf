# PaperLeaf QASPER 隐藏集 v1 首次盲测报告

本报告来自 `blind_holdout_first_run`。在读取私有答案前，`lock.json` 已固定 55 篇论文、
120 个问题、两名候选、K=5、切块参数、门控规则与检索实现 SHA-256。公开结果只包含聚合指标，
不包含逐题预测或私有证据标签。

索引包含 859 个页内 Chunk，本机索引构建耗时 7,884 ms。延迟只用于本次同机比较。

## 结论

开发期校准集上，自适应候选把 MRR@5 从 59.0% 提到 60.0%，且没有降低两个已知数据集的
Recall@5；但该差异在隐藏集上没有复现，两个方案的全部聚合指标完全相同。因此不能宣称
该门控带来泛化提升，也不把它接入生产默认检索链路。

本次协议刻意只比较检索排序，不在隐藏答案上选择拒答阈值。两名候选都会对检索结果生成
提取式回答，所以不可回答错误作答率为 100%；这不是可接受的产品结果，而是下一轮必须用
新校准集和新隐藏集解决的明确缺口。

按当前发布目标衡量：证据组完整命中达到 85% 门槛，非法引用为 0；页召回、首引页准确率、
引用覆盖率和不可回答控制均未达标。机器可读文件保留全部分子、分母、类别切分和锁信息。

## 解释边界

- 哈希向量是无需模型密钥的确定性下限，不等同于生产语义嵌入模型。
- 首引页准确率来自检索首项构造的确定性引用，不等同于完整 LLM 回答质量。
- holdout 已揭盲，任何后续结果只能标记为诊断；新的改进需要另建隐藏集。
