## 结论

引用结构与模型辅助支持核验总体稳定，但这不等于回答准确率。系统在不可回答题上
10/10 都产生了结论，且只有 26.2% 的引用落在人工 Gold 证据页；这两个缺陷阻止本轮
结果被表述为“回答准确率 95%”或“可靠拒答”。

## 原始证据

- `run_manifest.json`：环境、模型、镜像、数据锁与 Chunk 快照；
- `per_query_answers.jsonl`：100 道题的 Run、回答、引用与逐题核验；
- `metrics.json`：所有自动指标的分子和分母；
- `human_blind_review.jsonl`：30 道未评分盲评样本。

具体 SHA-256 记录在 `run_manifest.json`。逐条支持率由模型辅助 grader 生成，只能作为
辅助指标；在真实人员完成盲评前不得命名为人工准确率。
