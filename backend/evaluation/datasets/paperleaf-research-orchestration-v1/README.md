# PaperLeaf Research Orchestration V1

这是有界跨论文编排的冻结场景清单，不是模型准确率结果。

- `cases.jsonl` 固定 36 个规划、权限、回退与故障场景。
- `deterministic` 评测只验证强类型计划、分支边界、合并、预算和回退，不冒充真实模型 A/B。
- `live` A/B 必须在相同问题、相同用户、相同论文范围和相同模型配置下分别运行 v1/v2，并保存 Run ID 与人工标注。
- 修改已有 case 需要提升数据集版本；本版本只允许追加明确的新回归 case。

计划中的 `paper_ids` 是冻结占位 ID，只用于确定性组件测试，不代表真实论文或真实用户数据。
