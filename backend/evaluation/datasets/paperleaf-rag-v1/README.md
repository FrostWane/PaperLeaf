# PaperLeaf RAG v1 数据集

这是 PaperLeaf 的首个页级检索冻结集，创建于 2026-07-29。它面向“个人文献库内检索”场景，
问题会明确限制在一篇或多篇已选论文内，不评价开放互联网搜索排名。

## 构成

- 20 篇机器学习与 Agent 方向的公开 arXiv 论文；
- 120 个英文问题：100 个可回答、20 个不可回答；
- 30 个 dev 问题用于阈值选择，90 个 test 问题用于阶段对比；
- 110 个物理页证据锚点；
- 10 个跨论文对比问题和 10 个包含恶意指令的检索问题。

论文均固定到 `manifest.json` 中的 arXiv 精确版本。仓库只分发 Apache-2.0 许可的清单和人工
注释；PDF 版权仍归原作者或对应权利人所有，因此这里只保存官方下载链接、哈希与页数，
不重新分发 PDF。

## 文件

- `manifest.json`：论文版本、来源、SHA-256、页数、切块参数和配额；
- `annotations.json`：适合人工复核的注释源；
- `cases.jsonl`：由生成器产生并冻结的评测输入。

任何问题、页码或锚点变更都必须同时更新数据集版本，重新生成 `cases.jsonl`，并使用原始 PDF
通过完整校验。不要为了提高某个检索器的分数而静默修改 test 标注。
