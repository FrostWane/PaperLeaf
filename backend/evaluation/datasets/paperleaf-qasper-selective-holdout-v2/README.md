# PaperLeaf QASPER Selective Holdout v2

该数据集用于检验文献问答系统在“回答”与“拒答”之间的选择，而不只比较检索召回率。

## 数据边界

- 来源：QASPER `validation` split，注释许可证为 CC BY 4.0。
- 规模：23 篇论文、54 个问题；48 个可回答，6 个不可回答。
- 论文与 `paperleaf-qasper-calibration-v1` 完全不重合；构建器按无版本 arXiv ID 排除 29 篇校准论文。
- 问题、论文版本、下载地址、页数和 SHA-256 保存在仓库中；PDF 原件不重新分发。
- 正确答案、证据页和答案关键词保存在仓库外的私有 oracle 中。

不可回答题只占 6/54。该比例来自现有离线缓存中能够满足一致标注和页级映射要求的样本，不能把本数据集描述成平衡测试集。

## 评测协议

首次运行前必须提交 `lock.json`，锁定：

- 公开问题、私有 oracle 与论文清单的哈希；
- 检索、质量门禁和评分实现的哈希；
- 候选方案、`k`、哈希向量维度和排除数据集；
- 开发集校准结果的哈希。

首次揭盲会生成不可覆盖的回执。公开结果只含聚合指标，不含逐题预测和私有 oracle。

## 解释限制

- 该数据集与校准集论文不重合，但二者都来自 QASPER `validation` split。
- 当前协议使用无模型密钥的哈希向量与 BM25/RRF，属于可复现下限，不是生产级语义检索。
- 本轮只评估单篇论文的可回答/不可回答与物理页引用；部分支持、跨论文冲突仍需单独人工标注的数据集。
