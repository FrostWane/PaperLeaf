# PaperLeaf 正式隐藏集 v1

该数据集用于一次性的生产同源 RAG 正式验收。公开目录只保存论文清单、问题、
冻结协议和构建回执；人工证据 oracle 在首次运行前保存在私有证据目录中，SHA-256
已写入 `lock.json`。

数据集包含 70 篇未出现在既有 PaperLeaf RAG/QASPER 开发与评测集中的论文，问题
与页级证据来自 QASPER 人工标注。固定配额为：

- 50 道单篇问题；
- 30 道三篇论文组合问题；
- 10 道多页或多证据问题；
- 10 道不可回答问题。

所有 100 道题在同一个正式批次中运行七个预注册方案，固定 K=5。隐藏集首次结果
产生后不得继续针对该数据调参；任何后续复跑都必须标记为揭盲后诊断。

首次运行前的最终协议包含 50 道中文问题和 50 道英文问题。中文题由原 QASPER
问题做等义翻译，题目 ID、论文范围与人工证据组保持不变；该修订发生在任何隐藏
结果产生之前，并由更新后的 `questions_sha256` 冻结。

PDF 不随仓库分发，`manifest.json` 保存精确 arXiv 版本、文件 SHA-256 与物理页数。
缺论文、索引契约不一致、问题或 oracle 哈希漂移、逐题结果不完整时，执行器会以
`not_executed`/失败退出，不会缩小分母。
