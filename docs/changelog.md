# 更新记录

本项目遵循[语义化版本](https://semver.org/lang/zh-CN/)。早期开发阶段的接口仍可能调整，升级前请阅读对应版本说明并备份数据。

## 未发布

### 新增

- 集合改为最多五层的 Zotero 式父子树，支持多集合归属、父集合递归筛选、待整理范围、键盘展开与父集合选择器移动。
- 文献增加出版物元数据；PDF 本地识别优先，缺失时仅以公开 DOI 查询 Crossref，并避免覆盖并发用户修改。
- arXiv 导入保存精确版本元数据与 `journal_ref`，文献库增加出版物列并统一显示 ISO 最近阅读日期。
- 上传 PDF 时可以同时选择多个集合；文献库表格显示当前集合，并为每篇已有论文提供独立的集合管理入口。
- 增加真实账户菜单与退出登录，显示当前用户昵称和邮箱，并按 `/auth/me` 角色隐藏普通用户的管理入口。
- 增加可持久化的个人设置：昵称、小/标准/大字号、PDF 默认缩放、左右栏默认状态、翻译语言和 arXiv 搜索偏好。
- 管理后台将模型内部状态改为带用途说明的中文“AI 能力状态”，后台任务按等待、执行、完成和失败展示对应信息。

### 修复

- 删除标签模型、关系表、API、批量动作和全部前端入口；数据库迁移按既定破坏性策略丢弃既有标签数据。
- 跨文献问答改为提交集合 ID，由服务端递归解析用户可访问且索引就绪的论文范围，避免前端陈旧范围或注入论文 ID。
- 停用或启用用户改为明确文字操作并在停用前确认；服务端返回的最后一名管理员、当前管理员和重复用户原因会直接展示。
- 删除全局通知铃铛，并将应用正文/辅助字号下限统一到三档设计令牌；2K 视口无需浏览器缩放即可阅读。
- 上传完成后同时刷新论文、集合与标签查询，避免集合关联已经写入数据库、界面却仍显示旧数量或旧筛选结果。
- 上传与集合关联共用完整忙碌状态，避免文件上传达到 100% 后重复提交；多集合关联部分失败时会明确列出失败集合。
- 固定 `pdfjs-dist` 与 `react-pdf` 使用的 PDF.js 版本，并区分登录失效、组件版本不一致和普通加载失败提示，恢复真实 PDF 预览。

### 测试

- 增加多集合选择单元测试，以及已有论文增删集合的桌面、2K、平板和移动端端到端回归。
- Playwright 固定在独立的 3100 端口构建并启动 demo 数据生产服务，且不复用本地站点，避免正在运行的 real 模式 Docker 环境污染确定性端到端测试。
- 最后一名管理员保护改为仓库级原子操作：PostgreSQL 使用稳定顺序的行锁重新计数，内存仓库使用互斥锁；可选真实数据库集成测试验证并发保护和改密后的响应一致性。
- 里程碑 1 本地门禁通过后端 124 项、真实 PostgreSQL 2 项、前端 37 项、生产构建与 Storybook 构建；四视口 Playwright 42 项通过、6 项按专项视口设计跳过。

## 0.8.0 - 2026-07-31

### 新增

- 增加选择性回答指标：同时报告正确引用可回答覆盖率、过度拒答、不可回答错误作答、选择性风险和平衡安全准确率，避免用全拒答制造安全性高分。
- 增加只使用 dev oracle 的确定性门禁校准器；策略不满足预设风险与覆盖约束时明确返回“无推荐策略”。
- QASPER 构建器支持按既有 manifest 排除论文，并在公开回执中记录排除数据集哈希与数量，不记录本机私有路径。
- 增加与校准集论文交集为 0 的选择性回答隐藏集 v2，以及检索器、质量门禁、评分器三重实现锁和不可覆盖揭盲回执。

### 评测与测试

- 隐藏集 v2 包含 23 篇论文、54 个问题，其中 48 个可回答、6 个不可回答；首次盲测的页召回@5 为 59/66（89.4%），证据组完整命中为 44/48（91.7%）。
- 现有质量门禁把不可回答错误作答从 6/6 降到 3/6，但造成 24/48 可回答题过度拒答，正确引用后作答从 21/48 降到 9/48，选择性风险从 61.1% 升到 66.7%；因此不宣称该候选带来准确率或可靠性提升。
- CI 增加 v2 公开锁、问题数量和校准集论文隔离校验；实现漂移会在读取私有 oracle 前失败。
- 本地发布审计通过后端 Pytest 84 项、前端 Vitest 14 项、Ruff、Python 编译、TypeScript、ESLint、生产构建、Storybook 构建和容器配置；四视口 Playwright 33 项通过、3 项非 2K 字号检查按设计跳过。

## 0.6.0 - 2026-07-31

### 新增

- 增加基于 QASPER 人工标注的公开校准集与隐藏测试集；论文 PDF 继续只保存来源、精确版本、哈希和页数，不进入仓库。
- 增加替代证据组、证据组完整命中率与最佳证据组页召回率，支持同一问题存在多组正确证据。
- 增加隐藏集预注册锁：分别固定公开问题、私有 oracle、候选方案、协议与检索实现 SHA-256。
- 增加单次揭盲回执和公开输入 CI 校验；公共结果只保存聚合指标，不写逐题预测。
- 增加页级多粒度 RRF、向量权重消融与低词项覆盖时才启用的自适应候选。

### 修复

- QASPER 证据映射改为页覆盖预筛、稀有词起点候选与受限模糊匹配，避免对整页执行无界窗口比较。
- PDF 锚点校验增加 ASCII 退化路径，正确处理数学修饰符、软连字符和断行，同时保留 Unicode 原文校验。
- 自适应检索复用 BM25 排名，并跳过权重为零的通道，旧评测集 p95 从初版 106 ms 降至 45 ms；该延迟只作同机诊断。

### 评测与测试

- QASPER calibration 为 29 篇、60 问；QASPER holdout 为 55 篇、120 问，完整验证 55 份 PDF 与 183 个证据锚点。
- 唯一一次 holdout 盲测中，页级 RRF 与自适应候选结果相同：页召回 132/167（79.0%）、证据组完整命中 82/96（85.4%）、MRR@5 61.4%。校准集增益未泛化，因此候选不进入生产默认链路。
- 纯检索候选对不可回答题错误作答 24/24，继续作为待解决缺口，不把检索结果包装成完整回答质量。
- 后端 Pytest 增至 70 项，覆盖替代证据组、QASPER 转换、公开/私有拆分、锁漂移、单次揭盲、防覆盖与公开 CI 校验。

- 前端契约增加节点开始/完成、耗时和管理员模型状态映射；Playwright 增加运行轨迹可见性断言。

## 0.4.0 - 2026-07-31

### 新增

- 前端契约覆盖 `tool_finished.evidence_quality`；Playwright 覆盖跨文献证据摘要与 URL 页码跳转。
- 记录 BGE-small、Cross-Encoder、句窗 Cross-Encoder 和窗口 BM25 的负向诊断，不采用无收益方案。
