# 更新记录

本项目遵循[语义化版本](https://semver.org/lang/zh-CN/)。早期开发阶段的接口仍可能调整，升级前请阅读对应版本说明并备份数据。

## 未发布

## 0.2.0 - 2026-07-29

### 新增

- 在论文工作台加入“问答 / 概览 / 结构”三视图，前端接通证据化总结与结构图 API。
- 总结引用和结构节点均可跳转到 PDF 物理页；结构图使用 Mermaid strict mode，并保留可键盘访问的证据目录。
- 增加文献元数据编辑、失败或部分解析重试、删除二次确认和后台清理状态。
- 文献列表对索引中与删除中的项目自动刷新，上传后立即同步列表，并补充真实空状态。

### 修复

- `/demo` 现在强制使用固定数据源，不再受 `NEXT_PUBLIC_DATA_MODE=real` 影响或误请求真实 API。
- 真实论文工作台不再短暂显示固定论文、固定回答、模拟目录和无法验证的缩放值。
- 处理进度缺失时显示“正在索引”，不再把未知进度误写成 `0%`。

### 测试

- 前端单元测试增至 11 项，覆盖文献修改、重试、删除、总结和结构图 API 契约。
- Playwright 在 2560、1440、768、390 四个视口运行 24 个项目：21 项通过，3 项非 2K 字号检查按设计跳过。
- 生产构建、Storybook、后端 22 项 Pytest、Ruff 与 Python 编译检查通过。

## 0.1.0 - 2026-07-22

### 新增

- Next.js 文献工作台与固定数据演示模式。
- FastAPI 用户、文献、任务、问答和管理员接口。
- PostgreSQL/pgvector、MinIO 与后台 Worker 基础设施。
- 按物理页解析、混合检索、RRF、引用校验与证据不足拒答。
- LangGraph 受控 Agent、SSE 状态、arXiv 搜索与确认导入。
- Docker Compose、自检、持续集成与中文部署文档。

### 安全

- 私有对象存储、用户范围过滤、管理员内容边界与上传校验。
- Agent 工具白名单、步数限制、人工确认和文献提示词注入防护。
