# 更新记录

本项目遵循[语义化版本](https://semver.org/lang/zh-CN/)。早期开发阶段的接口仍可能调整，升级前请阅读对应版本说明并备份数据。

## 未发布

## 0.4.0 - 2026-07-31

### 新增

- Agent 增加页级证据质量契约，公开检索置信度、通道一致性、证据页数和可选答案支持状态。
- 增加可选的结构化答案支持检查；只保存支持结论、置信度与原因码，不保存隐藏推理。
- 增加可复现的 FastEmbed dense、Cross-Encoder、句窗重排和细粒度窗口检索诊断工具。

### 修复

- 混合检索先扩大候选池，再按论文与物理页去重；同一页的多个 Chunk 不再挤占多个 Top-K 位置，并合并关键词/向量通道信号。
- Agent 不再把“召回列表非空”直接当作证据充分；弱匹配和答案不受支持时进入拒答节点。
- SSE 引用补全论文标题、原文摘录和 PDF 跳转信息；跨文献引用链接现在可以直接打开目标物理页。
- 证据质量阈值增加 0~1 配置校验，非法生产配置在启动时失败。
- 跨文献提问在客户端接管表单前禁止提交，避免冷启动时触发原生表单重载；Playwright 固定使用演示数据，不再继承本机真实 API 模式。

### 测试

- 新增页聚合、双语词项覆盖、跨语言向量支持、弱匹配拒答、答案支持分层与阈值配置测试。
- 前端契约覆盖 `tool_finished.evidence_quality`；Playwright 覆盖跨文献证据摘要与 URL 页码跳转。
- 记录 BGE-small、Cross-Encoder、句窗 Cross-Encoder 和窗口 BM25 的负向诊断，不采用无收益方案。
- 0.4.0 发布审计通过后端 44 项、前端 13 项与四视口 Playwright 33 项；3 项非 2K 字号检查按设计跳过。

## 0.3.0 - 2026-07-29

### 新增

- 冻结首个页级 RAG 评测集：20 篇精确版本论文、120 个问题和 110 个物理页证据锚点。
- 增加无模型密钥的哈希向量、BM25、RRF、页去重、邻页与跨论文范围消融。
- 增加只在 dev 集选择阈值的拒答实验，以及 test 集分阶段机器可读指标和中文报告。
- 数据集校验器可核对配额、ID、页码；本地提供 PDF 时进一步核对 SHA-256、页数与页内锚点。

### 修复

- 评测引用现在同时校验论文 ID 与物理页，避免不同论文同页码被误判为正确。
- 指标增加页级 MRR、split/category 分组，并继续保留原始分子和分母。

### 测试

- CI 增加冻结数据集静态校验，且不下载或重新分发论文 PDF。
- 新增生成器、完整性校验、页级指标、检索通道、范围多样化和严格拒答单元测试。

## 0.2.1 - 2026-07-29

### 新增

- 文献库接通集合与标签的创建、编辑、二次确认删除，以及持久化的文献归属关系。
- 增加多选工具栏，可批量加入或移出集合、添加或移除标签，并批量归档与恢复。
- “全部文献 / 最近阅读 / 待整理 / 已归档”改为真实状态与动态数量，支持状态、年份、集合和标签组合筛选。
- 新增 `last_opened_at` 与 `archived_at` 持久状态、批量整理 API 和数据库迁移。
- 公开演示可从论文工作台进入固定数据文献库；上传、整理和阅读跳转均保持在演示数据源内。

### 修复

- 集合与标签列表现在返回真实 `paper_ids`，刷新页面后不再丢失筛选依据。
- 移动端文献表不再依赖横向滚动才能查看核心内容，处理状态合并到论文信息中。
- 调深次要文字令牌，修复浅灰背景上的 WCAG AA 临界对比度问题。

### 测试

- 前端 Vitest 增至 13 项，新增组织 CRUD、归属、批量动作和最近阅读契约覆盖。
- 新增四视口端到端任务，覆盖组织项 CRUD、批量加入/移出、归档/恢复、动态计数和横向溢出。
- 后端 23 项 Pytest 扩展验证归属返回、跨用户批量操作隔离、最近阅读、归档状态和 PostgreSQL 检索索引契约。
- 将全文与 trigram 检索索引纳入 ORM metadata，避免迁移漂移检查把历史索引误判为待删除对象。

## 0.2.0 - 2026-07-29

### 新增

- 在论文工作台加入“问答 / 概览 / 结构”三视图，前端接通证据化总结与结构图 API。
- 总结引用和结构节点均可跳转到 PDF 物理页；结构图使用 Mermaid strict mode，并保留可键盘访问的证据目录。
- 增加文献元数据编辑、失败或部分解析重试、删除二次确认和后台清理状态。
- 文献列表对索引中与删除中的项目自动刷新，上传后立即同步列表，并补充真实空状态。

### 修复

- `/demo` 现在强制使用固定数据源，不再受 `NEXT_PUBLIC_DATA_MODE=real` 影响或误请求真实 API。
- 真实论文工作台不再短暂显示固定论文、固定回答、模拟目录和无法验证的缩放值。
- 处理进度缺失时显示“正在索引”，不再把未知进度误写成 `0%`。

### 测试

- 前端单元测试增至 11 项，覆盖文献修改、重试、删除、总结和结构图 API 契约。
- Playwright 在 2560、1440、768、390 四个视口运行 24 个项目：21 项通过，3 项非 2K 字号检查按设计跳过。
- 生产构建、Storybook、后端 22 项 Pytest、Ruff 与 Python 编译检查通过。

## 0.1.0 - 2026-07-22

### 新增

- Next.js 文献工作台与固定数据演示模式。
- FastAPI 用户、文献、任务、问答和管理员接口。
- PostgreSQL/pgvector、MinIO 与后台 Worker 基础设施。
- 按物理页解析、混合检索、RRF、引用校验与证据不足拒答。
- LangGraph 受控 Agent、SSE 状态、arXiv 搜索与确认导入。
- Docker Compose、自检、持续集成与中文部署文档。

### 安全

- 私有对象存储、用户范围过滤、管理员内容边界与上传校验。
- Agent 工具白名单、步数限制、人工确认和文献提示词注入防护。
